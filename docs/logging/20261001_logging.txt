There is one common function used for almost all of the logging call through the codebase:

void add(int log_type, int sub_type, int p, float v0=0, float v1=0, float v2=0, float v3=0, float v4=0, float v5=0, float v6=0, float v7=0, float v8=0, float v9=0, const char* t1="", const char* t2="");



The timer ones use these:
   void add_tmrf(int type, const char *format, ...);
   void add_tmr1(int type, const char *tag, double dt);
   void add_tmr(int type, const char *txt);


'LOG_TMR' is used to mark log entries for profiling graphs
all the other 'LOG_TMR_xxx' are used to enable/disable specific logging



LOG_NET_SESSION
---------------
Is ony used to enable or disable sessions. (See sessions.txt)
Sessions is completely separate and uses the sqlite database.
